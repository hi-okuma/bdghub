ヒント提出（/submitHint0004）

HTTPメソッド：POST

リクエスト

{
  "roomId": <指定した部屋のroomId>,
  "uid": <子プレイヤーのuid>,
  "hint": <子プレイヤーが入力したヒント>,
}

{
  "success": true,
  "message": "",
}
